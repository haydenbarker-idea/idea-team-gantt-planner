# Email Snapshot Flow

Back to [[Home]]. Flow **"Project Schedules - email snapshot"** in Hayden's Power Automate
(default environment `Default-2e378968-efb3-40b6-b767-bec10a322606`, flow id
`6ea24adf-48b8-4a12-8d2c-13b86bd2ac86`). Scheduled every minute. Runs on Hayden's Excel Online
(Business), OneDrive for Business and Office 365 Outlook connections, so emails come from Hayden.

## How it works
1. Button **Run Email Snapshot to Client** (script `Email Snapshot to Client`) adds a row to
   `SnapshotRequests` on the hidden "Snapshot Requests" tab: Id, Requested (UTC), Tab, Requester, Status=Pending, Note.
2. Flow: *List rows present in a table* (filter `Status eq 'Pending'`).
3. *Apply to each* (concurrency 1):
   - *Find marker*: OneDrive `_snapshot-log/<Id>.done`. If found → skip (request already handled).
   - Otherwise scope *Process request*: create the marker → mark Working → copy workbook to
     `_snapshot-temp/snapshot-tmp-<guid>.xlsx` → wait 5 s → *Run script* Prepare Snapshot (tabName) →
     *Convert file* to PDF → *Get file content* of the copy → *Send an email (V2)* to Requester with both
     attachments (subject "Snapshot ready: <project> - forward to <client email>") → mark Sent (or Failed)
     → wait 90 s → delete the copy (retry after 4 min).

Folders live next to the workbook in OneDrive: `Project Schedules (test)/_snapshot-log` and `_snapshot-temp`.

## Maintaining it
- The loop is generated by `power-automate/make-loop.py <file id> <table id> <path>` as a
  classic-designer clipboard item (`power-automate/loop-live-workbook.json` = current live one).
  Paste: classic designer (toggle "New designer" off) → + New step → My clipboard → Ctrl+V → click item.

  script `ms-officescript%3A%2F%2Fonedrive_business_itemlink%2F01HQWHCLRBWYKVTVA57NDK6FH6UVRVXPLB`.
- To get IDs for another file: point *List rows* at it in the classic designer, then
  "..." → Copy to my clipboard and read the JSON.
- Stop it: flow details → Enabled toggle. While off, requests queue up and are sent when it's back on.
- Load: ~1,440 runs/day (most do nothing). Watch the owner's Power Automate limits.
